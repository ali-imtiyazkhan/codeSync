# CodeSync VS Code Extension

CodeSync allows you to share your VS Code files in real-time with your CodeSync session.

## Features

- **Connect to Room**: Join a collaborative session by entering a Room ID.
- **Start Sharing**: Share your active file with everyone in the room.
- **Real-time Sync**: Edits made in VS Code are synced to the web editor, and vice versa.

## Commands

- `CodeSync: Connect to Room`
- `CodeSync: Disconnect`
- `CodeSync: Start Sharing Current File`
- `CodeSync: Stop Sharing`
